## 📝 Screenshot Guidelines

### Technical Requirements

**Resolution:**
- Minimum: 1920x1080
- Recommended: 2560x1440 or higher
- Format: PNG (preferred) or JPEG

**Quality:**
- No compression artifacts
- Clear text readability
- Proper lighting in-game
- Clean UI (no debug overlays unless documenting that)

### Composition

**In-Game Screenshots:**
- Use daytime for clarity
- Clear weather conditions
- Hide unnecessary UI elements
- Focus on the feature being documented
- Include relevant context

**Console Screenshots:**
- Full terminal window visible
- Clear font rendering
- Complete log messages
- Sufficient context before/after key messages

**UI Screenshots:**
- Centered menu/interface
- All text clearly readable
- No cursor blocking important information
- Consistent UI theme

## 🔄 Updating Screenshots

### When to Update

- Major version releases
- Significant UI changes
- New features added
- Framework updates affecting appearance
- Bug fixes that change behavior

### Versioning

Include version number in filename for archives:
```
01_startup_console_v1.0.0.png
01_startup_console_v1.1.0.png
```

Keep latest in main docs folder:
```
docs/assets/screenshots/01_startup_console.png
```

Archive old versions:
```
docs/assets/screenshots/archive/v1.0.0/01_startup_console.png
```
